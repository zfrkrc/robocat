# Eski kaynak arşivi

Düzenleme: 2026-10-27. Bu klasör otomatik baskı, robot firmware'i veya PCB üretim kaynağı değildir.

## Taşınan upstream projeler

| Proje | İçerik / neden burada |
|---|---|
| [Nova-SM2](upstream/Nova-SM2) | Önceki quadruped sürümü; seçilen gövde seti Nova-SM3 |
| [BlackWidow-Hexapod](upstream/BlackWidow-Hexapod) | Altı ayaklı ayrı proje |
| [RobotArm-6DOF](upstream/RobotArm-6DOF) | Ayrı altı eksenli kol; RoboCat koluna doğrulanmış aktarım değil |
| [Pot_ProtoBox](upstream/Pot_ProtoBox) | Ayrı kutu projesi |
| [Spectrum-Analyzer](upstream/Spectrum-Analyzer) | Ayrı ses/ışık projesi |

Klasörlerin mevcut dosyaları değiştirilmeden, alt dizin yapılarıyla taşındı. Eski kök yolları artık `archive/upstream/` altındadır. Git geçmişi ve kökteki [LICENSE](../LICENSE) korunur; üçüncü taraf lisans koşulları ayrıca geçerlidir. Eski indirme/yer imi yolları yerine bu indeksi kullanın.
