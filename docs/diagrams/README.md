# Diyagram kaynakları

`python docs/diagrams/render_diagrams.py` iki SVG üretir:
- `docs/images/robocat-architecture.svg`
- `docs/images/robocat-power.svg`

Yalnız Python standart kütüphanesi gerekir. Bunlar kesin komponentli elektrik şeması değil, belgelenmiş sistem mimarisidir. Gerçek sinyal pin önerileri hardware/PINMAP_REV_A.csv içinde, açık güç gereksinimleri hardware/PCB_PLAN_REV_A.md içindedir.
